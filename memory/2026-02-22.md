
## Trading Bot Development - Position Sizing Risk Management

**Time:** 9:48 AM EST

### What We Built
Added dynamic position sizing module (`position_sizing.py`) with comprehensive risk management rules:

**Sizing Tiers:**
- Edge > 25% → 10% Kelly (high conviction)
- Edge 20-25% → 5% Kelly (standard)
- Edge 15-20% → 4% Kelly (conservative)

**Risk Limits:**
- Max 30% total bankroll exposure
- Max 6 concurrent positions
- Max 15% in single position
- Reduce to 3% when already 20%+ exposed

**Time Adjustments:**
- Same-day resolution: 50% size reduction
- Next-day resolution: 20% size reduction

**Weather Correlation Protection:**
- Tracks cities by weather region (northeast, midwest, etc.)
- 50% size reduction if 2+ positions in same region
- Prevents all positions losing to same storm system

### Strategy Decision
User asked about increasing position sizes for weather trading. Conclusion: Keep single trades conservative (4-5%) but add concurrent strategies instead of bigger bets.

**Ranking for $100 bankroll:**
